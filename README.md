# Homebrew Tap

Third-party Homebrew formulae and casks maintained by Oscar Hugo Paz.

## Available Formulae

- `mainwp-cli` — Command-line interface for the MainWP Dashboard REST API v2.

## Available Casks

- `lepton` — Snippet management app.

## Installation

Tap this repository:

```bash
brew tap oscarhugopaz/tap
```

Install any available formula or cask:

```bash
brew install oscarhugopaz/tap/<formula>
brew install --cask oscarhugopaz/tap/<cask>
```

For example, to install Lepton:

```bash
brew install --cask oscarhugopaz/tap/lepton
```

Lepton is not signed or notarized by Apple, so macOS may require manual authorization in Privacy & Security. This cask is maintained by this third-party tap and is not an official package from Lepton or Homebrew.
